プライバシーポリシー

対象と目的

この方針は運用者本人の個人用Google連携に適用されます。Googleデータはメールの重要度判定、予定・生活ルーチンの管理と通知のために利用します。

扱う情報

有効な権限と処理に応じて、Gmailの送信者、件名、日時、本文の一部、メッセージ識別子、Sheetsのルール・イベント・通知履歴、Calendarの予定、Driveの関連ファイルを扱います。

外部サービス

メールなどの内容の一部を、設定されたLLM/APIサービスへ分類・要約のため送信する場合があります。通知対象の要約は運用者が指定したSlackへ送信します。送信先サービスのデータ取扱いには各サービスの方針も適用されます。

保存と公開範囲

認証情報と処理状態は運用環境で管理し、ルーチン情報は指定されたGoogle Sheetsに、通知はSlackに保存します。本公開リポジトリにメール本文、認証情報、予定や家計簿などの個人データは掲載しません。不要になった記録の削除は運用者が各保存先で管理します。

目的の制限

Googleデータを販売したり、広告配信のために利用したりしません。取得したGoogleユーザーデータの利用および転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

アクセスの停止

運用者はGoogleアカウントの接続管理で権限を取り消し、監視ジョブを停止できます。

問い合わせ

公開説明については本リポジトリのIssuesをご利用ください。秘密情報や個人データを投稿しないでください。
